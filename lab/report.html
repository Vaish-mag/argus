Argus — self-healing moving-target defence

Experimental results: detection and recovery from web-root compromise, measured against a scripted manual recovery.

What was measured

A containerised web application (DVWA) is monitored by an autonomic controller structured as a MAPE-K loop. On confirmed tampering it preserves forensic evidence, isolates and destroys the compromised container, rebuilds from a hash-verified clean source, and promotes the replacement — with no human involved.

attack→detect→preserve evidence →isolate→destroy→restore →verify hashes→health check→promote
Metric definitions. MTTD = attack → detection. MTTR = detection → service promoted. Total recovery = attack → service healthy again. MTTR starts its clock at detection, so the manual arm's operator-notice delay lands in MTTD and cancels out of an MTTR-only comparison. Total recovery is the fair arm-to-arm comparison and is the figure to quote.

Threats to validity

  • The attack is a filesystem observable, not a working exploit. The harness writes an inert PHP marker reproducing the trace a webshell upload leaves. The detection layer is file-integrity monitoring, so the two are equivalent from the detector's point of view — but this is not exploit fidelity.
  • The baseline's notice delay is modelled, not observed. A fixed operator-notice delay stands in for human mean-time-to-acknowledge, and it drives the entire comparison. It requires justification against a cited industry figure.
  • DVWA is deliberately vulnerable and unrepresentative of a hardened production target. The healing loop is application-agnostic, so this affects the realism of the breach, not the validity of the recovery measurements.
  • Single-host lab. Network isolation is logical rather than physical; a production deployment would span hosts.
  • Measurement outliers present. One or more trials show durations far above the median, caused by the virtual machine stalling under memory pressure while wall-clock time continued. Medians are reported for this reason; means are distorted.
  • Small sample. Trial counts are low; these figures demonstrate that the pipeline works rather than providing publication-grade statistics.

Reproducing this

From the project root, inside the virtual environment:

python run_argus.py init-golden
python run_argus.py watch      # terminal 1
python run_argus.py run        # terminal 2
python lab/attacker/run_experiment.py --arm argus    --trials 20 --scenario webshell
python lab/attacker/run_experiment.py --arm baseline --trials 20 --scenario webshell
python lab/plot_results.py
